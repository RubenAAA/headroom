---
title: Grok Build Integration
description: Route Grok Build traffic through the Headroom Rust proxy for token compression and per-project savings attribution.
---

Point Grok Build at the local Headroom proxy: start `headroom-proxy`, set Grok's `base_url` to it, and launch `grok`.

## Quick Start

```bash
headroom-proxy --listen 127.0.0.1:8787 --upstream https://api.anthropic.com
```

In `~/.grok/config.toml` (or `$GROK_HOME/config.toml`), point the model at the proxy:

```toml
[model.grok-build]
base_url = "http://127.0.0.1:8787/v1"
```

In another terminal, from the same project directory:

```bash
grok
```

> The old Python wrapper (`headroom wrap grok-build`, with `--port`, `--no-proxy`, `--learn`, `--memory`, and `headroom unwrap grok-build`) lives in the read-only `upstream-python/` mirror. The steps above do the same thing by hand: proxy plus one `base_url`.

## Environment Variables

| Variable | Description |
|---|---|
| `GROK_HOME` | Override Grok config directory (default: `~/.grok`) |
| `XAI_API_KEY` | Grok API key (also accepts `GROK_CODE_XAI_API_KEY`) |

## Verify

```bash
curl -s localhost:8787/healthz
headroom savings
```

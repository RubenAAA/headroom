When agents hand off to each other, context gets replayed in full. SharedContext compresses what moves between agents using Headroom's compression pipeline, typically saving **~80% of tokens** on agent handoffs.

## Quick start

Shared context runs through the proxy `/ctx` endpoints (`index`, `fetch`, `get`, `search` — see [Proxy](/docs/proxy)). The old SDK classes (`SharedContext` in `headroom-ai`) live in the read-only `upstream-python/` mirror.

## API

### Storing and fetching

Store via `POST /ctx/index`, fetch via `POST /ctx/fetch` or `GET /ctx/get/{hash}`. Content compresses automatically through the proxy pipeline.



### `get(key, full?)`

Retrieve content. Returns the compressed version by default, or the original with `full=True`.



### `stats()`

Aggregated statistics across all entries.



### `keys()` and `clear()`

`keys()` lists all non-expired keys. `clear()` removes all entries.

## Configuration



Entries expire after `ttl` seconds. When `maxEntries` is reached, the oldest entry is evicted.

## Framework examples

The CrewAI / LangGraph / OpenAI-Agents-SDK examples used the old Python `SharedContext` class and live in the read-only `upstream-python/` mirror. The same handoff pattern works through the proxy: one agent indexes output with `POST /ctx/index`, the next fetches it compressed with `POST /ctx/fetch`.

## How It Works

Under the hood, `POST /ctx/index` runs the proxy compression pipeline and stores the original; `POST /ctx/fetch` returns the compressed form.mpressed version. `get(full=True)` returns the original.

The compression pipeline routes content to the best compressor:

- **JSON arrays** -- SmartCrusher (70-95% compression)
- **Code** -- CodeCompressor (AST-aware)
- **Text** -- Kompress (ModernBERT-based) or passthrough

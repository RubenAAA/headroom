title: Context Management
description: Automatic live-zone-only context management that compresses the newest content blocks while preserving the provider cache hot zone.

Context management is automatic inside the proxy pipeline (live-zone-only compression). Headroom **never drops messages** from the conversation history and does not do position-based or score-based context management.

## How It Works

Headroom compresses only the **newest content blocks** — the latest user message and the latest tool result / tool output. Compression is type-aware and only compresses content that benefits from compression.

The last N messages are always preserved, ensuring the model has immediate conversational context. Tuning is flag-driven on `headroom-proxy` (run `headroom-proxy --help`); the implementation lives in `crates/headroom-core/src/transforms/`. The old Python `compress()` / `HeadroomClient` API lives in the read-only `upstream-python/` mirror.

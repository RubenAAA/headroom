---
title: OpenCode Integration
description: Route OpenCode traffic through the Headroom Rust proxy for token compression and savings visibility.
---

Point OpenCode at the local Headroom proxy with a `headroom` provider using `@ai-sdk/openai-compatible`, pointing at `http://127.0.0.1:8787/v1`.

## Quick Start

Start OpenCode through the launcher (the `cclaude` equivalent) — it starts
the proxy if needed and injects the provider for that run only:

```bash
oopencode --context            # bare launcher, default setup
oopencode-work                 # work defaults: proxy + --auto
```

Then pick a routed model with `opencode -m headroom/<route>` or the
`/models` picker — the proxy's `/v1/models` advertises every route (e.g.
`headroom/claude-muse-spark-1.3`).

## By hand

Start the proxy:

```bash
headroom-proxy --listen 127.0.0.1:8787 --upstream https://api.anthropic.com
```

Add the provider to `opencode.json`:

```jsonc
{
  "provider": {
    "headroom": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Headroom Proxy",
      "options": {
        "baseURL": "http://127.0.0.1:8787/v1",
        "apiKey": "[redacted]"
      }
    }
  }
}
```

Then run OpenCode against it. To stop, remove the provider block.

> The old Python wrapper (`headroom wrap opencode` / `headroom unwrap opencode`, plus the `headroom-opencode` npm plugin) lives in the read-only `upstream-python/` mirror. The steps above do the same thing by hand: proxy plus one provider block.

## Verify

```bash
curl -s localhost:8787/healthz
headroom savings
```

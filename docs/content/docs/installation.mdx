## Prerequisites

- git, Rust via rustup
- `jq` and `lsof` (the installer warns if missing — the status line and restart script need them)

## install.sh

```bash
git clone https://github.com/RubenAAA/headroom.git ~/headroom
cd ~/headroom
./install.sh
```

This builds the release binaries and installs `headroom-proxy` and `headroom` to `~/.local/bin`, plus the `cclaude` launcher, `restart-headroom.sh`, the flags file (`~/.headroom-flags.sh`), the status line, and the review hooks. An existing `~/.headroom-flags.sh` is left alone (delete it to regenerate).

```
./install.sh [--no-build] [--link] [--hooks-into DIR]
  --no-build     skip cargo build; install whatever target/release holds
  --link         symlink the scripts and flags file into the checkout,
                 so editing the repo edits the live setup (for developing Headroom itself)
  --hooks-into   project whose sessions should run the review hooks
                 (default: $HOME, i.e. every session on this machine)
```

## Run

```bash
cclaude --context
```

`--context` is what puts the proxy in the path. Bare `cclaude` is passthrough; plain `claude` never touches the proxy.

## Verify

```bash
curl -s localhost:8787/healthz
headroom doctor
```

See [Quickstart](/docs/quickstart) and [Troubleshooting](/docs/troubleshooting).

## Docker

The root `Dockerfile` builds both the Python wheel and the Rust `headroom-proxy` binary. It is the image path, not the daily-driver path — local install above is what development uses.

## Environment

Every `headroom-proxy` flag also has a `HEADROOM_PROXY_*` environment variable (e.g. `--listen` → `HEADROOM_PROXY_LISTEN`, default `0.0.0.0:8787`). Run `headroom-proxy --help` for the authoritative list.

## Python mirror

The `headroom-ai` pip/uv package lives in the read-only `upstream-python/` mirror and is not built here.

# Working notes

The maintainer's notes and measurement logs, kept for the record.

They are not onboarding material, and parts of them go stale as the code moves.
Start at the root [README](../../README.md) instead.

## Triage views (extracted, sources stay in place)

- [`ideas/`](ideas/) — one file per untreated idea. Ships move to
  [`ideas/implemented/`](ideas/implemented/), measured declines to
  [`ideas/rejected/`](ideas/rejected/) (with the killing number). Plans stay
  in their original docs; only ideas and learnings are extracted.
- [`learnings/`](learnings/) — one file per durable finding, each with its
  evidence window and source. Refuted entries stay (they stop retests).

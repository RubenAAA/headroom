# Ideas

One file per untreated idea, extracted from the working notes. Sources stay
where they are; this is the triage view.

- Root: **open** — not yet done, not yet rejected.
- [`implemented/`](implemented/): shipped. Each file names the commit/flag.
- [`rejected/`](rejected/): measured and declined, with the number that killed it.

Conventions per file: status, source doc + section, value, concrete next step.
When an idea ships or dies, move the file (don't duplicate it).

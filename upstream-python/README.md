# upstream-python

Upstream [headroomlabs-ai/headroom](https://github.com/headroomlabs-ai/headroom)'s
Python package, mirrored here so upstream releases can be merged, diffed, and
ported into the Rust crates under `crates/`. This fork does not build, test,
install, or publish anything in it. Edit the Rust side instead, so upstream
merges keep applying cleanly. The root `README.md` says what this fork ships.
